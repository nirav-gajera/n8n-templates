How to use n8n

From downloaded JSON to a working automation.

Every template is a starting point. Import it into n8n, connect your own accounts, replace the placeholder values, test it safely, and then activate it.

Before you start

  • Have an n8n Cloud or self-hosted workspace.
  • Keep your API keys and credentials ready.
  • Read the template's setup guide before activating it.
01

Download and import

Download the JSON file, open n8n, choose Workflows → Import from File, and select the downloaded file. The nodes and connections will appear on a new workflow canvas.

02

Connect credentials

Open every node marked with a credential warning and select or create the matching credential. Credentials stay in your n8n account; the JSON file does not contain your secret keys.

03

Replace values and IDs

Update spreadsheet IDs, Airtable bases, Telegram chat IDs, email addresses, webhook URLs, model settings, and other values described in the guide. Never leave example IDs in a production workflow.

04

Understand expressions

Values like {{ $json.email }} are n8n expressions. They read data from earlier nodes. Use the expression editor and the node's input preview to confirm that each field resolves to the value you expect.

05

Test before activating

Run the workflow manually with safe test data. Check each node's input and output, confirm the final API or email action, and review error branches before connecting real customer or business data.

06

Activate and improve

Turn on the workflow only after a successful test. Add retries, notifications, filters, approval steps, or database nodes as your process grows. Keep a backup export before making major changes.
